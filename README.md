# AgendaPro — Landing Page

Landing page de vendas de um sistema de **agendamento online** para pequenos negócios, como salões, barbearias e clínicas. O objetivo da página é levar o visitante a falar pelo WhatsApp e contratar um dos planos.

**[▶ Ver a página no ar](https://lucascamposf-dev.github.io/agendai-landing/)**

<img src="docs/desktop.png" width="640" alt="Topo da landing page no computador: título 'Agendamento online para o seu negócio' e botões Quero contratar e Ver planos"> <img src="docs/mobile.png" width="190" alt="A mesma página no celular, com menu recolhido">

## O que tem na página
- **Hero** com proposta de valor e dois caminhos: contratar ou ver os planos.
- **Funcionalidades** do sistema e uma prévia do **controle financeiro**.
- **Planos** (Básico, Pro e Premium), cada um com botão de **WhatsApp e mensagem pronta** sobre aquele plano.
- **Menu responsivo**, que vira menu hambúrguer no celular.

## Tecnologia
- Um único `index.html` com HTML, CSS e JavaScript puros, sem framework e sem build.
- Layout responsivo com CSS Grid e Flexbox, tema escuro e tipografia Syne + DM Sans.
- Publicado com **GitHub Pages**.

## Rodar localmente
É só abrir o `index.html` no navegador.
